# Cirilo

An iPhone character companion for everyday stories and details people choose to keep.

[Cirilo at Burrito’s Labs](https://burritoslabs.com/catalogue/cirilo/)

## Technology

Swift, SwiftUI, Speech, AVFoundation and Apple Foundation Models on supported devices.

## Architecture

A character state system controls expression and turn-taking. Speech can become a reviewable transcript. Conversation and memory actions pass through product rules.

## Product behavior

Remembered details are reviewed before storage. Features vary with device capabilities and available local model support.
